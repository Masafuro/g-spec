```md
# ECショップ基本フロー
ユーザーが商品を購入して注文が確定するまでの一般的な流れを示します。
以下のブロックは、購入フローの概要説明です。
```

実行　トップページ表示
実行　商品検索
分岐　|検索結果なし| 検索エラー表示
実行　商品詳細ページ表示
実行　カート追加
実行　購入手続き開始

```md
## ユーザー情報と配送情報
次にユーザー情報や配送先情報などを確認するステップです。
ログインしていない場合はログインに誘導します。
```

実行　ユーザー情報確認
分岐　|未ログイン| ログイン画面へ遷移
実行　配送先情報入力
実行　クーポン入力
分岐　|クーポン無効| クーポンエラー表示

```md
## 在庫確認と決済処理
注文処理における中核部分です。
在庫不足や決済エラーが発生した場合の分岐も含まれます。
```

実行　在庫確認
分岐　|在庫不足| 在庫エラー表示
実行　決済処理開始
分岐　|クレジット認証失敗| 決済エラー表示
実行　注文確定
実行　注文完了画面表示

```md
## エラー処理系 1：検索エラー
検索時に商品が見つからなかった場合の処理です。
```

実行　検索エラー表示
実行　トップページへ戻る
---
```md
## エラー処理系 2：ログインエラー
ログイン失敗時のハンドリングです。
```

実行　ログイン画面へ遷移
実行　ログイン処理
分岐　|ログイン失敗| ログインエラー表示
実行　ユーザー情報確認
---
```md
## エラー処理系 3：クーポンエラー
クーポンが無効だった場合の処理です。
```

実行　クーポンエラー表示
実行　クーポン再入力誘導
実行　購入手続き開始
---
```md
## エラー処理系 4：在庫エラー
在庫不足時の処理で、ユーザーをカートへ戻します。
```

実行　在庫エラー表示
実行　カートへ戻る
---
```md
## エラー処理系 5：決済エラー
決済に失敗した場合のリカバリフローです。
```

実行　決済エラー表示
実行　支払い方法再入力誘導
実行　決済処理開始

```md
## 管理用バッチ処理
ここからはシステム管理側の夜間バッチなどを想定した処理です。
```

実行　管理バッチ開始
実行　注文一覧取得
実行　支払未完了注文抽出
実行　未完了注文キャンセル処理
実行　在庫数量再調整
実行　日次レポート作成
実行　管理バッチ終了
