# G-spec

G-spec は、自然な文章に近い形で仕様を記述し、そのまま構造化されたフローチャートを生成するための軽量記述言語です。  
仕様書としての読みやすさと、Mermaid による視覚的な処理構造の把握を両立することを目的にしています。

G-spec の特徴は、次の三点にまとめられます。

処理構造は「実行」「分岐」「---」の三つの最小構文で記述する。  
文章としての説明は Markdown ブロック ```md ～ ``` の中で自由に書ける。  
Markdown と G-spec をファイル内で任意に交互に配置でき、その順番で最終的な Markdown が生成される。

フローを図示する部分以外は Markdown の力をそのまま使えるため、説明文や背景、図解、表などを混在させた読みやすい仕様書を作ることができます。

---

## 使い方

G-spec を記述したファイルを用意し、変換スクリプトを実行すると、  
gspec.txtからMarkdown と Mermaid を統合した `flowchart.md` が生成されます。

```
python gen_g-spec.py
```

実行すると、Markdown と Mermaid ブロックを組み合わせた出力が作成されます。

---

## G-spec の基本構文

### 実行  
処理の直列を表す行です。  
直前の実行や分岐から、このノードへ矢印が接続されます。

```
実行 処理名
```

### 分岐  
条件付きの遷移を表します。  
現在のノードから条件付き矢印を生成します。

```
分岐 |条件名| 遷移先ノード
```

### ---（ストリーム区切り）  
処理の流れを分離します。  
次の実行は新しい流れとして扱われます。

```
---
```

### Markdown ブロック  
説明文、背景、注釈、外部仕様などを自由に書く領域です。  
出力ではそのまま Markdown として反映されます。

````md
```md
ここに説明を書く。
必要なだけ Markdown を利用できる。
```
