# G-spec  
自然文に近い記述でフローチャートを生成する軽量仕様記述言語

G-spec は、仕様書をできるだけ自然な書き方で記述し、  
そのまま Mermaid のフローチャートへ自動変換できる「軽量仕様言語」です。

複雑な表記や構文を覚える必要はありません。  
次の三つの構文だけで記述できます。

- **実行**（処理の直列表現）
- **分岐**（条件付き遷移）
- **---**（ストリーム切り替え）

構造化されたフローチャートが簡単に生成され、  
設計レビューやドキュメント化がはるかに容易になります。

---

# 特徴

- **自然文に近い仕様記述**  
  仕様書を書くような感覚で書けます。

- **自動フローチャート化**  
  G-spec を Mermaid の flowchart 記法に変換します。

- **最小限の構文**  
  読みやすさを最優先し、「実行」「分岐」「---」の三つの構文のみを採用。

- **日本語に完全対応**  
  ノード名は日本語のままで OK（内部で安全な ID に変換されます）。

- **ファイルの扱いが簡単**  
  `.gspec` ファイルを Python スクリプトに渡すだけで `.md` が得られます。

---

# 例：G-spec から Mermaid へ

## G-spec 記述（example.gspec）

```
実行　開始
実行　ユーザー入力受付
分岐　|無効入力| エラー処理
実行　入力データ解析
実行　処理実行
分岐　|処理失敗| エラー処理
実行　結果出力
実行　終了
---
実行　エラー処理
実行　エラーメッセージ表示
実行　終了
```

## 変換後（Mermaid）

````mermaid
flowchart TD
    n0["開始"]
    n1["ユーザー入力受付"]
    n2["エラー処理"]
    n3["入力データ解析"]
    n4["処理実行"]
    n5["結果出力"]
    n6["終了"]
    n7["エラーメッセージ表示"]

    n0 --> n1
    n1 -->|無効入力| n2
    n1 --> n3
    n3 --> n4
    n4 -->|処理失敗| n2
    n4 --> n5
    n5 --> n6

    n2 --> n7
    n7 --> n6
